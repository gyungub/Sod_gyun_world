메인 퀘스트는 Sod 가입 → 6개 지역 필드보스를 차례로 처치 → 균교에서 균계 접근권 획득 → 균계 수도의 대균 처치 → 마지막 경계, 순서로 이어진다.
Sod에 가입하면 보스를 처치하고 평판이 쌓일수록 Recruit → Reaver → Harbinger → Archslayer → Primarch로 자동 승급한다.
